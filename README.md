# ShopSphere – E-commerce Application

## About the Project
ShopSphere is a backend e-commerce application developed using Java and Spring Boot. It provides REST APIs for user authentication, product management, cart operations, order management, and checkout.

## Technologies Used
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA / Hibernate
- MySQL
- Maven
- REST APIs
- Postman

## Features
- User registration and login
- Password encryption using BCrypt
- JWT-based authentication
- Product CRUD operations
- Product search and filtering
- Shopping cart management
- Order creation and management
- Checkout with stock updates
- Revenue and dashboard summary APIs

## Database
MySQL database: `shopsphere_db`

## How to Run
1. Install Java 21 and MySQL.
2. Create the `shopsphere_db` database.
3. Configure your local database credentials in `application.properties`.
4. Run `ShopsphereApplication.java` from your IDE or start the application using Maven.

## Important Note
Database credentials and other secrets should not be committed to GitHub. Configure them locally before running the application.
